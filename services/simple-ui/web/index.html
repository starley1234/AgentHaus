💡 Как пользоваться простым UI

  • Новый диалог: кнопка слева → введи задачу → агент начнёт работу, файлы появятся в ./projects/<id>/
  • Чат: пиши задачи на русском, агент выполняет команды, пишет файлы, показывает результат
  • Быстрые действия: кнопки .env, Тесты, Docker — вставляют готовые промпты для ru-плагинов
  • Файлы: список файлов из рабочей директории диалога, клик — просмотр содержимого
  • Навыки: включить/отключить все — массовые действия, сохраняются в настройках
  • Сервисы-деньги: слева ссылки на коммерческие сервисы (BOM, микро-SaaS, SEO) с биллингом Robokassa
  • Прода: этот UI работает на том же бэкенде, но проще и быстрее основного React (меньше JS, меньше чанков)

Бэкенд определяется автоматически: если открыт через gateway :8290 — используется прокси /api/proxy, если через основной порт :8300 — используется /api (проксируется в контейнере). Ошибка ERR_CONNECTION_REFUSED исправлена.
