🏭 Фабрика микро-SaaS

Автономный завод маленьких платных инструментов. Каждый запуск = новый микро-SaaS с лендингом. Работает в браузере, без бэкенда — можно продавать как статический сайт на Gumroad, Vercel, Product Hunt.

💡 Идеи микро-SaaS (популярные, продаются по $5-19):

  • PDF to Excel / CSV / JSON — для бухгалтеров, закупок
  • CSV Cleaner — удалить дубликаты, пустые строки, форматировать
  • JSON Formatter + Validator — с подсветкой ошибок
  • Image Compressor — сжатие без потери качества
  • Background Remover — удалить фон (через Canvas API)
  • QR Generator — с лого, цветами
  • Password Generator — с правилами
  • Regex Tester — тестер регулярных выражений
  • Color Palette Extractor — из картинки
  • Markdown to HTML / PDF — конвертер
