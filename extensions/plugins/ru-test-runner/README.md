# Плагин запуска тестов (RU)

Запускает тесты проекта (npm, pytest, cargo, go) и формирует понятный отчёт на русском с анализом причин падений.

## Возможности

- **Автоопределение** тест-раннера по файлам проекта (`package.json`, `pyproject.toml`, `Cargo.toml`, `go.mod`)
- **Запуск** с правильными флагами и выводом
- **Анализ падений** — парсинг логов, указание файла и строки ошибки
- **Рекомендации** по исправлению
- **Покрытие** — запуск с coverage, если настроено

## Использование

```
Запусти тесты
Запусти тесты для файла src/api/plugins-service.test.ts
Почему падают тесты?
Покажи покрытие тестами
```
