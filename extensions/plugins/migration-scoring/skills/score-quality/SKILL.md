Оцените качество миграции, выставив оценки покрытия и корректности для каждой пары файлов исходный-целевой.

**Предварительное условие**: Должен существовать файл карты миграции (см. навык `migration-mapping`).

См. [references/scoring-criteria.md](references/scoring-criteria.md) для шкал 1-5.

## Формат вывода

Сохраните оценки как JSON-файл:

```json
{
  "source_file_1.cbl": {
    "coverage": 4,
    "correctness": 5,
    "justification": "Вся логика расчётов мигрирована. Округление налогов совпадает с поведением COBOL."
  }
}
```

## Процесс оценки

Для каждого исходного файла и его сопоставленных целевых файлов:

1. **Определите ключевую функциональность** в исходнике
   - Бизнес-логика, операции с данными, поток управления, обработка ошибок

2. **Проверьте покрытие** в цели
   - Представлена ли каждая функция/параграф?
   - Покрыты ли все поля данных и ветки кода?

3. **Проверьте корректность**
   - Дают ли расчёты те же результаты?
   - Обрабатываются ли граничные случаи так же?

4. **Задокументируйте обоснование**
   - Конкретная присутствующая/отсутствующая функциональность
   - Известные расхождения

## Инкрементальная оценка

Если файл оценок уже существует, обновите его новыми оценками, а не заменяйте полностью.
