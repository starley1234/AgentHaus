# Плагин Git-помощник (RU)

Русскоязычный помощник для работы с Git и GitHub. Упрощает рутинные операции: создание веток, коммиты по конвенциям, пуш, создание PR, просмотр истории и разрешение конфликтов.

## Возможности

- **Создание веток** с проверкой нейминга (`feature/`, `fix/`, `chore/`)
- **Умные коммиты** — генерация сообщений по conventional commits на русском
- **Проверка статуса** — `git status`, `git diff`, `git log` с понятным объяснением
- **Создание PR** через `gh` CLI с автозаполнением описания
- **Безопасность** — никогда не пушит напрямую в `main/master` без подтверждения

## Навыки

| Навык | Описание |
|-------|----------|
| `git-helper` | Основной навык для всех Git-операций |

## Использование

```
Помоги создать ветку feature/new-auth
Сделай коммит изменений по conventional commits
Создай PR из текущей ветки
Покажи историю коммитов за последнюю неделю
```

## Требования

- Git
- GitHub CLI (`gh`) для создания PR (опционально)
