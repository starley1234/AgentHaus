# Плагин очистки кода (RU)

Запускает линтеры, форматтеры и проверки типов, исправляет авто-исправимые проблемы и формирует отчёт на русском.

## Возможности

- **Автоопределение**: eslint, prettier, ruff, black, cargo clippy, go fmt
- **Форматирование**: `npm run format`, `ruff format`, `cargo fmt`
- **Линт с автофиксом**: `eslint --fix`, `ruff check --fix`
- **Проверка типов**: `tsc --noEmit`, `mypy`
- **Очистка**: неиспользуемые импорты, console.log, TODO

## Использование

```
Отформатируй код
Запусти линтер
Проверь типы
Почисти неиспользуемые импорты
```
