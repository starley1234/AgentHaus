# Плагин Docker-помощник (RU)

Русскоязычный помощник для работы с Docker и Docker Compose. Помогает собирать образы, проверять логи, перезапускать сервисы и чистить неиспользуемые ресурсы.

## Возможности

- **Сборка и запуск**: `docker compose up -d --build`, проверка статуса
- **Логи**: просмотр логов контейнеров с фильтрацией
- **Диагностика**: `docker ps`, `docker stats`, проверка healthcheck
- **Очистка**: удаление остановленных контейнеров, неиспользуемых образов и volume
- **Безопасность**: никогда не удаляет volume с данными без подтверждения

