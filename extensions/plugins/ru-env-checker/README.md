# Плагин проверки окружения (RU)

Проверяет `.env` файлы, переменные окружения и секреты. Сравнивает `.env` с `.env.example`, ищет захардкоженные секреты и отсутствующие обязательные переменные.

## Возможности

- **Сравнение `.env` vs `.env.example`** — какие переменные отсутствуют или лишние
- **Поиск секретов в коде** — `API_KEY`, `PASSWORD`, `SECRET` в исходниках
- **Проверка безопасности** — `.env` в `.gitignore`?, права файла 600?
- **Генерация `.env.example`** из текущего `.env` с замаскированными значениями
- **Валидация форматов** — URL, порты, булевы значения

## Использование

```
Проверь .env файлы
Сравни .env с .env.example
Найди захардкоженные секреты в коде
Сгенерируй .env.example
```
