# web-captcha — прохождение CAPTCHA в браузере

Навык для агента: когда сайт просит «докажи, что ты человек», агент действует
как **аккуратный пользователь**, а не как бот-обзорщик. Основной сценарий:
сделать `browser_get_state --include_screenshot`, посмотреть на экран, найти
точки клика (`center_x/center_y`) и кликнуть или ввести ответ.

## Зачем появился навык

Браузерный тулсет умеет кликать по явным индексам, но капчи часто находятся в
`iframe`, рисуются картинками/канвасом или требуют координаты мыши. Поэтому к
навыку добавлены два инструмента:

- `browser_click_coordinates x y` — клик по viewport-координатам;
- `browser_move_mouse x y` — подвести курсор (наведение, hover, более «человечный»
  путь перед кликом).

`browser_get_state` также теперь отдаёт `center_x/center_y`,
`viewport_position` и `absolute_position` для интерактивных элементов.

## Состав

- `SKILL.md` — инструкция для агента (детекция типов, порядок, ограничения).
- `scripts/captcha_playbook.py` — без-зависимая справка по типам капчи:
  ```bash
  python3 scripts/captcha_playbook.py --list
  python3 scripts/captcha_playbook.py recaptcha_image
  python3 scripts/captcha_playbook.py escalate
  ```

## Как включить

Навык регистрируется в вендоренном каталоге
(`extensions/marketplaces/openhands-extensions.json`), после пересборки образа
(`docker compose up -d --build`) агент подхватывает его по триггерам
«капча», «recaptcha», «докажи что ты человек» и т.п.

## Важная оговорка

Этот навык не рекламирует и не реализует **массовый автоматический обход**
капчи. Для легитимных сценариев (регистрация по просьбе владельца, вход в
сервис, заполнение формы) он помогает сделать это один раз аккуратно. Если сайт
повторно требует капчу или речь идёт о мошенничестве/платежах — агент обязан
остановиться и спросить владельца.
