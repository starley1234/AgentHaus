# Web Captcha — аккуратное прохождение проверок на сайтах

Цель этого навыка — **не обходить капчу «в лоб»**, а действовать как аккуратный
пользователь: понять, что перед тобой, посмотреть на экран, один раз правильно
навести мышь и кликнуть. Обычно современные капчи решаются **по клику мышью**,
поэтому главное — знать, куда подвести и где нажать.

## Перед началом

1. Всегда `browser_get_state --include_screenshot` — нужен и текст (`index`),
   и **позиции** (`center_x/center_y/viewport_position`). Без скриншота не
   догадывайся, что на экране.
2. Если сомневаешься в типе — запусти сводку:
   ```bash
   python3 <путь-к-навыку>/scripts/captcha_playbook.py --list
   ```
   и по типу:
   ```bash
   python3 <путь-к-навыку>/scripts/captcha_playbook.py recaptcha_image
   ```
   (путь навыка: `$EXTENSIONS_REPO/skills/web-captcha/scripts/captcha_playbook.py`
   или `/opt/agent-canvas/extensions/skills/web-captcha/scripts/captcha_playbook.py`).
3. Не вводи данные владельца, если капча не связана с формой, которую просил
   пользователь.

## Как определить тип

| Признак на скриншоте/в DOM | Тип | Что делать |
|---|---|---|
| Квадрат с галочкой, `iframe` с `recaptcha` | reCAPTCHA checkbox | клик по галочке (index или центр), дождись следующего экрана |
| Сетка из 9 картинок + задание | reCAPTCHA image | выбери нужные карточки по скриншоту, кликай по центрам |
| Логотип hCaptcha, сетка/рамки | hCaptcha | клики по центрам нужных объектов |
| Искажённый текст + поле ввода | текстовая | распознай текст и `browser_type` |
| «2 + 3 = ?» | математическая | посчитай и `browser_type` |
| Ползунок/пазл | sliding | не имитируй drag; 1 попытка, затем человек/VNC |
| Иконка Turnstile / «Verify you are human» | Cloudflare Turnstile | подожди 3–5 сек, при виджете — кликни |
| Не понял | unknown | скриншот + эскалация |

## Порядок прохождения (общий)

1. `browser_get_state --include_screenshot`.
2. Выбери способ:
   - обычная кнопка/галочка → `browser_click <index>`;
   - изображение/область без удобного index → **`browser_move_mouse center_x center_y`**,
     короткая пауза, затем **`browser_click_coordinates center_x center_y`**.
3. Подожди (перечитай `browser_get_state`), проверь, появилось ли новое задание.
4. Если появилась сетка изображений — повтори выбор по скриншоту.
5. **Максимум 2–3 попытки** на один сайт. Дальше — `escalate`: остановись и
   спроси владельца (в Telegram через `notify ask` или в чате).
6. После успеха подтверди результат: `browser_get_content` или следующее
   действие, которое просил пользователь.

## Координаты и «куда подвести мышь»

`browser_get_state` теперь возвращает для каждого интерактивного элемента:

```json
{
  "index": 7,
  "tag": "img",
  "text": "...",
  "viewport_position": {"x": 120, "y": 340, "width": 80, "height": 80},
  "center_x": 160,
  "center_y": 380
}
```

- **center_x / center_y** — точка, куда наводить и кликать.
- Если элемент находится внутри капчи-iframe и токен не появился в общем списке —
  сделай `browser_get_state` ещё раз; часто карточки появляются после клика по
  галочке. Если их всё равно нет, `browser_click_coordinates` по скриншоту —
  это осознанный шаг, но только после того, как названы координаты на скриншоте.
- Позиции — **viewport-координаты**; не прибавляй к ним `scroll` вручную — мы
  уже отняли смещение.

## Чего НЕ делать

- Не кликать наугад сотни раз — это увеличивает риск блокировки и сужает доверие
  к агенту.
- Не вводить чужой/неуместный email и не регистрироваться без явной просьбы
  владельца.
- Не использовать сторонние «решатели капчи» (сервисы/API) для массового обхода —
  нарушает ToS сайтов и может привести к блокировке.
- Не считать, что задача «выполнена», если не увидел подтверждение успеха.
- Если сайт просит пройти капчу после каждой страницы (или это человеческая
  идентификация/платёж) — не проходи её без явного разрешения владельца.

## Диагностика

| Симптом | Что делать |
|---|---|
| `browser_click_coordinates` не существует | пересобери образ (`docker compose up -d --build`) — инструменты добавляются в SDK |
| Капча появляется повторно 3+ раз | эскалация владельцу (нормально для WAF/чувствительных сайтов) |
| Карточки не видны после галочки | подожди или обнови `browser_get_state`; иногда нужен небольшой delay |
| Это платёж/закон регистрации | остановись и спроси, не проходи капчу за владельца без явного разрешения |
| Нужен drag/puzzle | скажи владельцу и предложи VNC (`OH_ENABLE_VNC=true`) либо ручной проход |
