# Как превратить AgentHaus в продукт, приносящий деньги — план модернизации

Ты уже имеешь самохостимый центр управления для агентов-программистов с русской локализацией, светлой темой, оффлайн-режимом и вендоренным каталогом. Это хорошая база, но сейчас это форк OpenHands без чёткой бизнес-модели. Ниже — конкретные идеи, как сделать продукт полезным и монетизируемым.

## 1. Позиционирование — что продавать

**Текущее позиционирование:** "Самохостимый центр управления для агентов-программистов: русская локализация, светлая тема, автономный режим, вендоренный каталог навыков."

**Проблема:** слишком общее, конкурирует напрямую с OpenHands (который бесплатный и с большим комьюнити).

**Предлагаемое позиционирование для EU/RU рынка:**

> **AgentHaus — GDPR-совместимый, самохостимый AI-инженер для команд, которые не могут отправлять код в облако.**
> 
> Для компаний в EU (особенно DE), где нельзя использовать Claude Code / Copilot из-за GDPR, IP, секретности. Работает полностью оффлайн с Ollama, vLLM, LM Studio. Русская локализация для команд из СНГ в EU. Готовые коммерческие автоматизации: авто-ревью PR, QA запуском кода, фиксы уязвимостей, релиз-ноты.

**Целевые сегменты (где деньги):**

1. **EU SMEs (10-100 dev) в DE, NL, CH** — не могут использовать US облака из-за GDPR, хотят self-hosted AI. Бюджет €500-2000/мес на инструменты.
2. **Русскоязычные команды в EU (Berlin, Frankfurt, Prague, Limassol)** — хотят интерфейс на русском, поддержку локальных LLM. Твоя локализация — конкурентное преимущество.
3. **Аутсорс/аутстафф компании (RU, BY, KZ, EU)** — продают клиентам "AI-усиленную разработку", используют onboarding-плагин для аудита репозиториев.
4. **Финтех, e-commerce, medtech** — где безопасность и QA критичны, готовы платить за vulnerability-remediation и qa-changes.

## 2. Техническая модернизация (что улучшить в коде)

### P0 — Стабилизация (1 неделя, уже частично сделано)

- ✅ Перевод плагинов на русский (сделано)
- ✅ Фикс "Плагины не найдены" (сделано: fallback + Marketplace.load)
- ✅ Продакшен Docker (сделано: prod compose, логи ротация, healthcheck, бэкап скрипт)
- ✅ Bulk enable/disable навыков и удаление (сделано)
- **Добавить:** CI для проверки перевода (`check-russian-translation.yml`), унификация версий actions, тесты для plugin.json валидации

### P1 — Enterprise-фичи (2-4 недели, приносят деньги)

**a) Мульти-тенантность и команды:**
- Сейчас: один пользователь, один volume. Для коммерции нужны команды, проекты, RBAC.
- Сделать: добавить `organizations` таблицу в `automation/automations.db`, добавить роли owner/developer/viewer, добавить UI для приглашения в команду.

**b) SSO и безопасность:**
- Добавить OIDC (Keycloak, Auth0) для логина, а не только `ADMIN_KEY` в заголовке
- Добавить audit log: кто, когда, какой диалог создал, какие файлы изменил
- Добавить RBAC для плагинов: какие плагины доступны каким командам

**c) Поддержка приватных LLM (ключевое для EU):**
- Уже есть `host.docker.internal` для Ollama, но нет UI для лёгкого добавления локальной модели
- Сделать: в `LLM settings` добавить пресеты "Ollama local", "vLLM local", "LM Studio" с авто-определением моделей (`/api/tags` для Ollama)
- Добавить бенчмарк локальных моделей: скорость, качество, стоимость

**d) Биллинг и лимиты:**
- Добавить `max_budget_per_task` уже есть, но нет общего биллинга
- Интеграция Stripe: usage-based, €0.10 per 1k tokens или €19 per user/month
- Дашборд расходов: сколько потрачено на LLM, какие диалоги дорогие

**e) Бэкап и восстановление в UI:**
- Сейчас бэкап только через скрипт `prod-up.sh --backup`
- Добавить в UI кнопку "Бэкап" и "Восстановить" с прогрессом

### P2 — Масштабирование (1-3 месяца)

- **Kubernetes:** Helm чарт для деплоя в k8s, с Postgres вместо SQLite, S3 для storage
- **Multi-arch:** `docker buildx` для amd64/arm64 (для Mac M1/M2 dev)
- **Bundle оптимизация:** сейчас chunks >500KB, нужен code-splitting, lazy load для markdown, terminal, Monaco
- **Мониторинг:** Prometheus метрики, Grafana дашборд, Sentry для ошибок
- **Документация:** сайт на Docusaurus с доками на русском и английском, видео-гайды

## 3. Коммерческие плагины и автоматизации (что продавать как фичи)

Уже есть ценные: `pr-review`, `qa-changes`, `vulnerability-remediation`, `release-notes`, `onboarding`. Их можно упаковать как "AI DevOps Pack" за €199/мес.

**Новые коммерческие плагины для разработки (идеи):**

1. **ru-security-audit-pro** — глубокий аудит безопасности: поиск eval, SQL-инъекций, XSS, проверка лицензий, секретов. Продавать как "Security Pack" для финтеха.

2. **ru-api-tester-pro** — авто-тестирование API из OpenAPI спеки, генерация Postman коллекции, проверка breaking changes. Для SaaS.

3. **ru-i18n-manager** — управление переводами: поиск отсутствующих ключей, сравнение en/ru, автоперевод через LLM. Для продуктовых компаний.

4. **ru-db-migrator** — проверка миграций БД, объяснение схемы, генерация ER-диаграмм. Для enterprise.

5. **ru-performance-profiler** — профилирование, flamegraph, bundle analyzer, рекомендации по оптимизации. Для e-commerce где скорость = конверсия.

**Автоматизации для продажи (через `automation` сервис):**

- **Еженедельный аудит безопасности** (Trivy + ru-security-audit-pro) → создаёт PR с фиксами
- **Авто-ревью всех PR** (pr-review) → комментарии в GitHub
- **QA каждого PR** (qa-changes) → отчёт PASS/FAIL
- **Генерация релиз-нотов** (release-notes) → обновление GitHub Release
- **Onboarding нового репозитория** (onboarding) → генерация AGENTS.md и отчёт готовности

Каждая автоматизация — cron, можно продавать как подписку.

## 4. Модели монетизации (как брать деньги)

### Модель 1: Self-hosted лицензия (лучше для EU)

- **Open Core:** база (AgentHaus + 11 плагинов) — бесплатна (MIT), как сейчас
- **Pro (€49/user/month или €499/company/month):**
  - SSO, RBAC, audit log, команды, бэкап в UI
  - Поддержка приватных LLM с UI
  - Биллинг и лимиты
  - Приоритетная поддержка
  - White-label (свой лого, домен)
- **Enterprise (€1999/month):**
  - On-prem установка с поддержкой, Helm чарт, Postgres, S3
  - Кастомные плагины под клиента
  - SLA, обучение команды

**Как реализовать:** добавить лицензионный ключ в `.env` (`LICENSE_KEY`), проверять в `entrypoint.sh`, отключать Pro фичи если нет ключа. Продажа через сайт + Stripe.

### Модель 2: Cloud + Self-hosted hybrid (как OpenHands)

- **Cloud версия** (hosted by you) — €19/user/month, с твоими LLM ключами, без установки
- **Self-hosted** — бесплатно, но с ограничением 3 пользователя, дальше Pro
- **Преимущество:** cloud для быстрого старта, self-hosted для GDPR

### Модель 3: Маркетплейс навыков/плагинов (как Shopify App Store)

- Разработчики публикуют навыки/плагины в твой маркетплейс
- Ты берёшь 20-30% с каждой продажи
- Пример: навык для 1С, для Bitrix, для специфичных EU compliance проверок
- Твоя русская локализация привлекает разработчиков из СНГ

### Модель 4: Консалтинг и внедрение (быстрые деньги)

- **Аудит репозитория** (€500-2000) — используешь onboarding плагин, делаешь отчёт готовности, предлагаешь фиксы
- **Внедрение AgentHaus** (€2000-10000) — установка, настройка LLM, обучение команды, создание кастомных навыков
- **Кастомные плагины** (€1000-5000 за плагин) — под конкретный бизнес клиента

**Твоя локация Frankfurt — плюс:** много компаний в Rhein-Main хотят GDPR-совместимый AI, но не знают как. Ты можешь быть локальным экспертом.

### Модель 5: Usage-based для автоматизаций

- Каждая автоматизация (PR review, QA, vuln fix) стоит токены
- Продаёшь пакеты: 100 PR reviews за €99, 1000 за €499
- Клиент подключает свой GitHub, ты делаешь webhook → запускаешь агента → результат

## 5. Go-to-market — как найти клиентов

**Неделя 1-2: Подготовка продукта**
- Доделать P1 фичи (SSO, биллинг, бэкап в UI)
- Сделать лендинг на русском и английском: agenthaus.dev (или .com) с описанием "GDPR AI Engineer"
- Записать 3 видео: установка за 5 мин, PR review, QA
- Опубликовать в каталоге OpenHands extensions как "AgentHaus — Russian, self-hosted"

**Неделя 3-4: Первые клиенты (бесплатно за отзыв)**
- Найти 5 компаний в Frankfurt/Berlin через LinkedIn: "GDPR self-hosted AI code review"
- Предложить бесплатный аудит репозитория через onboarding плагин + установку AgentHaus
- Попросить отзыв и кейс-стади

**Месяц 2: Платные**
- Запустить Pro за €49/user с Stripe
- Написать в русскоязычные чаты в EU: Berlin dev, Frankfurt dev, Deutscher IT Freelancer с RU
- Опубликовать на Habr, VC.ru статью "Как мы сделали GDPR-совместимый AI-инженер для DE компании"

**Месяц 3: Масштаб**
- Добавить маркетплейс, пригласить разработчиков
- Сделать партнёрство с Ollama, vLLM — они ищут UI для self-hosted

## Итог

AgentHaus имеет шанс, если позиционировать не как "ещё один OpenHands", а как **GDPR-решение для EU + русская локализация**. Твои фиксы для продакшена, перевода плагинов и новые ru-плагины — уже хорошая база. Добавь SSO, биллинг, бэкап в UI и продавай как Pro, параллельно делая консалтинг по внедрению.

Начни с консалтинга (быстрые деньги) → затем Pro лицензия (MRR) → затем маркетплейс (масштаб).
