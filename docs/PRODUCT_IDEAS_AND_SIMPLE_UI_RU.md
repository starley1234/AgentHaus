# Идеи как сделать хороший продукт + альтернативный простой UI

## Проблема текущего UI

Основной UI AgentHaus (React + Vite, форк OpenHands) — мощный, но сложный для новичка:
- 25+ роутов (`skills-plugins.tsx`, `mcp.tsx`, `automations-list.tsx`, `llm-settings.tsx` и т.д.)
- Тяжёлые чанки: `vendor-markdown 479KB`, `vendor-terminal 341KB`, `skills 510KB`, `vendor-styling 527KB` → медленная загрузка, особенно на слабом интернете
- Много настроек: LLM profiles, agent profiles, MCP, secrets, condensers — новичок теряется
- Нет простого режима: всё сразу, нет прогрессивного раскрытия

Для коммерции нужен **простой UI** который можно показать клиенту за 30 секунд и он поймёт.

## Решение: альтернативный простой UI

### Что сделал: `services/simple-ui/` (порт `/simple-ui/` через gateway :8290)

Минималистичный интерфейс поверх того же бэкенда :8000, без React, один HTML файл:

**3 колонки:**
- **Левая (260px):** список диалогов + быстрые действия (.env, Тесты, Docker, Формат, Git) + ссылки на денежные сервисы (BOM, микро-SaaS, SEO, Meeting Notes, Robokassa)
- **Центр:** чат с агентом (сообщения user/agent/system), поле ввода, кнопки триггеров `/onboarding`, `/codereview`, `/qa-changes`, `/release-notes`
- **Правая (280px):** файлы (список из workspace, клик → просмотр), навыки (✅/❌ + bulk Включить все / Отключить все), плагины (список + ссылка на управление)

**Фичи:**
- Создание нового диалога через prompt
- Отправка сообщений в существующий диалог через `POST /api/conversations/{id}/events`
- Просмотр файлов через `GET /api/workspaces/{id}/files`
- Bulk навыки: `POST /api/settings` с `disabled_skills: []` (включить все) или всеми именами (отключить все)
- Прокси `POST /api/proxy/*` → `AGENT_SERVER_URL` для прямых запросов
- Авто-обновление списка диалогов каждые 5 сек

**Почему лучше для новичка:**
- Один файл HTML, <10KB JS, без чанков, грузится мгновенно
- Только 3 действия: новый диалог, написать задачу, посмотреть файлы
- Русская локализация, подсказки "Файлы в ./projects/<id>/"
- Ссылки на коммерческие сервисы с ценами

**Запуск:**
```bash
./services/run.sh simple-ui   # отдельно на своём порту
# или через шлюз:
./services/run.sh             # gateway на :8290 → /simple-ui/
# в Docker уже в образе, т.к. COPY services/ и gateway монтирует все services/
```

Открой: http://localhost:8290/simple-ui/ или http://localhost:8300/simple-ui/

### Идея 2: "Simple Mode" в основном React UI

Добавить переключатель в `root-layout.tsx` или `settings`:

- Тумблер "Простой режим" в header
- Когда включён — скрывает:
  - MCP, Automations, Secrets, Condenser, App Settings
  - Оставляет только: Home (чат), Files, Skills (с bulk), Plugins
- Сохраняет в localStorage `simpleMode: true`

Реализация: 1 час, добавить `useSimpleMode` хук и условный рендеринг в `ExtensionsNavigation`.

### Идея 3: Telegram-бот как UI

Для максимального удобства — Telegram бот поверх AgentHaus:

- Пользователь пишет в Telegram: "/start проект X"
- Бот создаёт диалог через `POST /api/conversations`, отправляет сообщения
- Агент отвечает, бот пересылает файлы, логи
- Оплата через Robokassa прямо в Telegram (кнопка "Оплатить")

Что нужно: сервис `services/telegram-bot/` с `node-telegram-bot-api`, webhook, маппинг chatId → conversationId.

### Идея 4: VS Code Extension

- Команда "AgentHaus: Start Task" в палитре
- Открывает webview с простым UI (чат + файлы)
- Использует тот же бэкенд, но внутри VS Code

## Идеи как сделать хороший продукт (не только UI)

### 1. Продукт = набор узких сервисов, а не один большой чат

Текущий AgentHaus — это "всё в одном чате". Для бизнеса лучше **специализированные продукты** с простым UI, каждый решает одну дорогую задачу:

| Продукт | Текущий сервис | Цена | Клиент |
|---------|---------------|------|--------|
| BOM-парсер | bom-parse, pdf-bom-api | €0.20/стр | Заводы DE |
| 3D по фото | nq9n-vision-to-openscad | €5/модель | Etsy продавцы |
| Книга → сайт | book-site | $19/книга | Авторы, коучи |
| Доки → сайт | docs-site | €9/репо | Open-source мейнтейнеры |
| Конспект встреч | meeting-notes, meeting-notes-pro | €0.10/встреча | Команды (GDPR) |
| Микро-SaaS | micro-saas-factory | $5/инструмент | Малый бизнес |
| SEO сайт | seo-affiliate-site | €199/сайт | Аффилиат маркетологи |
| Оплата | robokassa-payment | — | Все сервисы |

Каждый сервис — отдельная папка с `config.json` + `server.mjs` + `web/index.html` + `price`. Gateway на :8290 показывает витрину с ценами. Это уже реализовано.

**Что доработать:** сделать `services/registry.json` с категориями (Производство, 3D, Контент, Бизнес) и фильтрами в витрине.

### 2. Шаблоны проектов (Project Templates)

Добавить в простой UI кнопку "Создать проект из шаблона":

- Лендинг кофейни, SaaS, портфолио, интернет-магазин (через `frontend-design` навык)
- Telegram бот, Discord бот, API на FastAPI
- Каждый шаблон — это промпт + список навыков

Реализация: файл `services/simple-ui/templates.json` с 10 шаблонами, при клике создаёт диалог с готовым промптом.

### 3. Автономные агенты как работники

Использовать `debate` сервис как пример: 2-3 агента с разными ролями (писатель, критик, исследователь) обсуждают тему N раундов с ограниченным контекстом и арбитром.

Для продукта: сделать **"Отдел"** — например, "Отдел контента" (writer + seo + designer), "Отдел разработки" (engineer + reviewer + qa), который можно нанять на задачу.

UI: выбор отдела → тема → запуск дебатов → сайт-стенограмма + итоговый артефакт.

### 4. Локальные LLM как фича для EU (GDPR)

В DE компании не могут использовать OpenAI из-за GDPR. Твой козырь — **оффлайн режим** с Ollama, vLLM, LM Studio через `host.docker.internal`.

Что доработать:
- В `simple-ui` добавить селектор "Локальная модель" с авто-определением `GET http://host.docker.internal:11434/api/tags`
- Бенчмарк: скорость, стоимость, качество
- Лендинг "GDPR AI Engineer, полностью оффлайн"

### 5. White-label для агентств

Агентства в Frankfurt хотят продавать клиентам "AI-усиленную разработку" под своим брендом.

Сделать:
- В `.env` добавить `BRAND_NAME`, `BRAND_LOGO`, `BRAND_COLOR`
- В `gateway.mjs` и `simple-ui` использовать эти переменные
- Скрипт `scripts/white-label.sh` который собирает образ с брендом клиента за 1 команду

Продавать как услугу: €2000 за white-label + €500/мес поддержка.

### 6. Обучение и сертификация

- Курс "Как использовать AgentHaus для заработка" (на основе `AUTONOMOUS_MONEY_MAKING_RU.md`)
- Сертификат "AgentHaus Certified Developer" после прохождения теста
- Продавать курс за €199, сертификат — €49

## Твой план: что делать сейчас

**День 1: Запусти простой UI**
```bash
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
./services/run.sh  # gateway на :8290
# открой http://localhost:8290/simple-ui/ и http://localhost:8290/ (витрина с ценами)
```

**День 2: Добавь шаблоны в простой UI**
- Создай `services/simple-ui/templates.json` с 5 шаблонами (лендинг, бот, API)
- Добавь кнопки в левую панель

**День 3: Сделай лендинг для продукта**
- Простой HTML в `services/simple-ui/web/landing.html` с описанием "GDPR AI Engineer для DE компаний, от €19"
- Добавь форму заявки через Robokassa

**Неделя 2: Первые клиенты**
- Найди 3 компании в Frankfurt через LinkedIn, предложи бесплатный BOM-парсер + простой UI
- Покажи витрину http://localhost:8290/ с ценами — это уже продукт

## Итог

Хороший продукт — это не сложный React с 25 роутами, а **простой UI (3 колонки) + набор узких платных сервисов с ценами**, каждый решает одну дорогую задачу и продаётся через Robokassa с минимальным участием.

Простой UI уже реализован в `services/simple-ui/`, gateway показывает цены. Дальше — шаблоны, white-label, Telegram бот и поиск клиентов.

Открой http://localhost:8290/simple-ui/ — это и есть альтернативный удобный UI.
